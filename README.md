# Manuel de français

A French course from A1 to A2 that runs in the browser and installs as an app on Android (Chrome menu → Add to Home screen).
Lessons, spaced review, listening and speaking practice, mock exams. Works offline once opened.

Progress is stored only in the browser on each device (Réglages → Sauvegarde to export or import a backup file). Nothing personal is stored in this repository.
